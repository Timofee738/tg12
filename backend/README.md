# Telegram Bot для Репетиторов 📅🎒

Telegram-бот для автоматизации записи учеников на занятия с двухэтапной верификацией и динамическим календарем. Написан на Python с использованием асинхронных библиотек.

## ✨ Функционал

*   **Двухэтапная регистрация:** Новый ученик подает заявку, которая отправляется админу (репетитору) на подтверждение через интерактивные инлайн-кнопки.
*   **Динамический календарь:** Бот автоматически генерирует расписание на 5 дней вперед. С наступлением новых суток календарь сдвигается сам.
*   **Персонализированная сетка времени:** Ученик видит свободные слоты (`⏰`), чужие брони (`❌`) и свои собственные активные записи (`👤 Ваша запись`).
*   **Изоляция экранов:** Почти весь процесс записи происходит внутри одного сообщения через редактирование текста (`edit_text`), что избавляет чат от спама.

## 🛠️ Стек

*   **Язык разработки:** Python 3.10+
*   **Фреймворк:** [aiogram 3.x](https://aiogram.dev) (Asyncio Telegram Bot API)
*   **ORM:** [SQLAlchemy 2.0](https://sqlalchemy.org) (Асинхронный режим)
*   **База данных:** PostgreSQL
*   **Контейнеризация:** Docker & Docker Compose

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Timofee738/tg12.git
cd backend
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге проекта и заполните его вашими данными:
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwXyZ  # Токен от @BotFather
ADMIN_ID=123456789                              # Ваш Telegram ID
DATABASE_URL=postgresql+asyncpg://postgres:postgres@db:5432/postgres
```

### 3. Запуск через Docker Compose
Проект полностью настроен для запуска в контейнерах. Выполните команду для сборки и старта всех сервисов:
```bash
docker compose up -d --build
```
*Бот автоматически подключится к базе данных, проверит структуру таблиц и начнет слушать сервер Telegram.*
